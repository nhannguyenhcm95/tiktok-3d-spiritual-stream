# THƯ MỤC CHỨA MÔ HÌNH 3D (.GLB)
Bạn có thể đặt file `player.glb` (xuất từ Tripo 3D hoặc Blender) vào thư mục này:
- Đường dẫn: `./assets/models/player.glb`
- Game tự động nạp qua `GLTFLoader`.
- Nếu chưa có file .glb, hệ thống sẽ tự động kích hoạt **Hàm dựng Nhân vật 3D Đa Khớp (Articulated Character)** mặc áo tràng/áo lam có cử động mượt mà ngay lập tức!
